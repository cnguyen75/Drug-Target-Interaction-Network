# Screenshots Guide

## 📸 **Screenshots to Capture**

### **1. Network Visualization Tab**
- **Main Interface**: Show the 2D network graph with controls
- **3D View**: Switch to 3D visualization
- **Node Selection**: Hover over a node to show details
- **Graph Walks**: Show expanded network with walks slider
- **Network Stats**: Display the statistics panel

### **2. Similarity Analysis Tab**
- **Drug Search**: Show drug dropdown and search interface
- **Similarity Results**: Display list of similar drugs
- **Target Similarity**: Show target similarity analysis
- **Results Panel**: Show detailed similarity scores

### **3. Link Prediction Tab**
- **Prediction Interface**: Show drug/target selection
- **Prediction Results**: Display ML prediction with confidence
- **Model Performance**: Show ROC-AUC and other metrics
- **Example Predictions**: Multiple drug-target pairs

### **4. Advanced Analytics Tab**
- **Discovery Insights**: Show drug discovery analysis
- **Community Detection**: Display community network graph
- **Drug Combinations**: Show combination recommendations
- **Loading States**: Show progress indicators

### **5. ML Evaluation Tab**
- **Model Comparison**: Show baseline vs ML performance
- **Calibration Plots**: Display model reliability curves
- **Performance Metrics**: Show comprehensive evaluation
- **Leaderboard**: Display model rankings

## 🎯 **Screenshot Tips**

### **Quality Guidelines**
- **Resolution**: 1920x1080 or higher
- **Format**: PNG for best quality
- **Browser**: Use Chrome/Firefox with clean interface
- **Window**: Full-screen or large window
- **Data**: Use interesting, diverse examples

### **Naming Convention**
```
screenshots/
├── 01-network-visualization.png
├── 02-network-3d.png
├── 03-similarity-analysis.png
├── 04-link-prediction.png
├── 05-advanced-analytics.png
├── 06-ml-evaluation.png
├── 07-community-detection.png
└── 08-drug-combinations.png
```

### **What to Avoid**
- ❌ Personal data or sensitive information
- ❌ Debug information or error messages
- ❌ Unfinished loading states
- ❌ Poor quality or blurry images
- ❌ Too much text (hard to read)

### **What to Include**
- ✅ Clean, professional interface
- ✅ Interesting data examples
- ✅ Clear feature demonstrations
- ✅ Good contrast and readability
- ✅ Representative results
